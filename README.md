# Kali Linux Virtual Environment Setup 💻

## Overview
This repository contains the documentation and execution logs for my minor project on setting up a secure penetration testing lab. The project demonstrates the foundational skills required for safe, isolated cybersecurity testing.

## Objectives Achieved
* **Hypervisor Configuration:** Deployed a secure, isolated virtual machine using Oracle VirtualBox.
* **System Provisioning:** Installed and configured Kali Linux (Debian-based) for security assessments.
* **Network Anonymity:** Performed MAC address spoofing using `macchanger` to mask physical hardware identifiers.
* **Access Control:** Enforced the principle of least privilege by configuring standard user accounts with specific `sudo` permissions.

## Technologies Used
* **OS:** Kali Linux
* **Virtualization:** Oracle VirtualBox
* **Command Line Tools:** `apt`, `ifconfig`, `macchanger`, `usermod`
